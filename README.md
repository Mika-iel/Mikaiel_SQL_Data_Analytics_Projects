# Mika_SQL_Projects


## Pizza Business Analysis Project (SQL Project 1)
### Overview

This project focuses on analysing the backend operations and business performance of a pizza business using MySQL. The objective was to design a structured relational database, analyse operational data, and extract business insights related to orders, sales performance, inventory management, and staffing.

The data analysis was further extended into Power BI, where interactive dashboards were created to visualise key performance indicators. The Power BI dashboard can be viewed in my Power BI Data Analytics Portfolio.

Credits for the original dataset and project inspiration go to LearnBI.

### Tools Used
* MySQL
* Navicat
* QuickDatabaseDiagrams.com
* Power BI

### Database Design & Preparation
* Created an Entity Relationship Diagram (ERD) using QuickDatabaseDiagrams.com.
* Defined primary keys and relationships between tables.
* Normalised the database structure to reduce redundancy and improve data integrity.
* Exported the relational database structure into MySQL syntax.
* Created and populated database tables using Navicat import tools.
The database model can be viewed in the Images folder.

### SQL Analysis

SQL queries were developed to analyse key areas of the business, including:
### Orders & Sales
* Total orders and revenue analysis
* Sales trends
* Top-performing pizza items
* Order distribution
### Inventory / Stock Control
* Ingredient usage
* Stock-related analysis
* Product demand patterns
### Customer & Delivery Analysis
* Delivery vs pickup performance
* Address/location analysis
### Staff Analysis
* Staff performance and operational insights
